# Troubleshooting

If the backend cannot start, use **Archive settings → Copy diagnostics**. The copied
report excludes catalogue content, media paths, filenames, people labels, and keys.
You can also open the data folder from that screen. For a locked database, close
other Archive instances; for an unreachable folder, reconnect/mount it and reopen.

The database and cache are valuable derived data. Back them up by copying the
app-data folder while Archive is closed. To restore, close Archive and replace its
app-data folder with the backup. Do not alter source media while troubleshooting.
